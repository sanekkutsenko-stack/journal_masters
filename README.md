# Журнал посещаемости Мастеров · СОтворчество

Веб-приложение на GitHub Pages, данные хранятся в Supabase (проект `journal-masters`).

## Первый запуск новой базы
1. Выполнить `supabase/schema.sql` в SQL Editor.
2. В Authentication → Sign In / Providers → Email отключить «Confirm email».
3. Зарегистрироваться на сайте — первый сотрудник становится администратором.
4. Загрузить книгу Excel на стартовом экране (позже — «Управление» → «Книга Excel»).

- Демо без входа и сервера: откройте сайт с `?demo` в конце адреса.
- Тема: светлая / тёмная (кнопка в боковой панели или в меню «Ещё» на телефоне).

## Файлы
| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | разметка и дизайн (обе темы, мобильная версия) |
| `core.js` | общие помощники: даты, склонения, тема, уведомления |
| `cloud.js` | вход, регистрация, приглашения, вызовы сервера |
| `sync.js` | отметки, очередь изменений, синхронизация |
| `journal.js` | экран журнала: неделя на компьютере, день на телефоне |
| `stats.js` | статистика, зона риска, контроль заполнения, карточка ученика |
| `excel.js` | выгрузка и разбор Excel |
| `manage.js` | управление: ученики, сотрудники, история |
| `curators.js` | работа кураторов с родителями: еженедельный список и отметки о разговорах |
| `import.js` | загрузка книги Excel администратором и сборка журнала |
| `supabase/schema.sql` | вся серверная часть: таблицы, функции, права, хранилище (выполнить один раз в Supabase) |
| `tour.js` | обучение при первом входе (подсветка, стрелки, подсказки) |
| `demo.js` | демо-режим на вымышленных данных |
| `app.js` | запуск |
